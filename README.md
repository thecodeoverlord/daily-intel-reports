# Daily Intel Brief — Reports

Published reports for the **Daily Intel Brief**: a daily open-source summary of
geopolitics, military, economic, and cyber / space / critical-infrastructure
developments.

This repository is **generated output only**. It is written by a private source
tree; nothing here is edited by hand.

## Latest

- [`latest.json`](latest.json) — machine-readable pointer to the newest edition
- [`index.md`](index.md) — archive of every edition
- [`feed.xml`](feed.xml) — RSS 2.0 feed, newest first

## Raw URLs

```
https://raw.githubusercontent.com/thecodeoverlord/daily-intel-reports/main/latest.json
https://raw.githubusercontent.com/thecodeoverlord/daily-intel-reports/main/feed.xml
```

## Layout

| Path | Contents |
|---|---|
| `briefings/YYYY-MM-DD.md` | Long-form brief |
| `briefings/YYYY-MM-DD.json` | Structured edition |
| `feed.xml` | RSS 2.0 feed |
| `latest.json` | Pointer to the newest edition |
| `index.md` | Archive index |

Every item carries a source link and a HIGH / MED / LOW confidence grade. See the
source note at the foot of each brief for method and known gaps.
